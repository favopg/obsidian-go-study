# Obsidian Go Study

Obsidianで囲碁の勉強を効率化するためのプラグインです。問題集の管理、解答、進捗状況の確認をObsidian上で行うことができます。

## 主な機能

- **問題集の一覧表示**: `Dataview`プラグインと連携し、特定のタグ（`igo-problem`など）やプロパティ（`igo_problem`）を持つファイルを問題として自動的にリストアップします。
- **インタラクティブな解答機能**: 
    - SGF形式の碁盤を表示し、クリックまたはプルダウンメニューから解答を選択できます。
    - 正解・不正解を視覚的なアニメーション（丸・バツ）でフィードバックします。
- **進捗管理**: 問題ごとに「完了（completed）」状態を記録し、問題集全体の達成度を表示します。
- **リボン・コマンド対応**: リボンアイコンやコマンドパレットから素早く問題集にアクセスできます。
- **自動ポインター表示**: 「練習問題」セクション配下のリストアイテムにマウスをホバーすると、クリック可能であることを示すポインターに変わります。

## 前提条件

このプラグインを最大限に活用するには、以下のプラグインのインストールと有効化が推奨されます：

- [Dataview](https://blacksmithgu.github.io/obsidian-dataview/): 問題の抽出と進捗管理に使用します。
- [Go Board Viewer](https://github.com/j2masamitu/obsidian-goboard-viewer): 碁盤の表示に使用します。
- [BRAT](https://github.com/TfTHacker/obsidian42-brat): 開発版プラグインの導入に使用します。

## 使い方

1. **問題の作成**: Markdownファイルのフロントマターに `igo_problem: true` またはタグに `#igo-problem` を追加します。
2. **プラグインの起動**: 左側のリボンにあるサイコロアイコンをクリックするか、コマンドパレットから `Igo Study` を実行します。
3. **解答**: 表示された問題一覧から問題を選択し、碁盤をクリックして解答します。

## ディレクトリ構成

- `main.ts`: プラグインのメインロジック（モーダル制御、イベントハンドリング）。
- `styles.css`: 碁盤上のエフェクトやUIのスタイリング。
- `manifest.json`: プラグインのメタ情報。
